💎 ダイヤ倍率計算機

投資したダイヤ数に対して、獲得後に増加したダイヤ数と倍率を自動計算するPWA（Progressive Web App）です。

スマートフォンのブラウザから利用でき、対応環境ではホーム画面に追加してアプリのように使用できます。

⸻

📱 機能

① 30投資

* 元のダイヤ数を入力
* 獲得後ダイヤ数を入力
* 増加ダイヤ数を自動計算
* 30投資に対する倍率を自動計算

② 300投資

* 元のダイヤ数を入力
* 獲得後ダイヤ数を入力
* 増加ダイヤ数を自動計算
* 300投資に対する倍率を自動計算

③ 3000投資

* 元のダイヤ数を入力
* 獲得後ダイヤ数を入力
* 増加ダイヤ数を自動計算
* 3000投資に対する倍率を自動計算

④ 30000投資

* 元のダイヤ数を入力
* 獲得後ダイヤ数を入力
* 増加ダイヤ数を自動計算
* 30000投資に対する倍率を自動計算

⸻

🧮 計算式

増加ダイヤ数

増加ダイヤ数
= 獲得後ダイヤ数 − 元のダイヤ数

各投資の倍率

① 30投資
倍率 = 増加ダイヤ数 ÷ 30
② 300投資
倍率 = 増加ダイヤ数 ÷ 300
③ 3000投資
倍率 = 増加ダイヤ数 ÷ 3000
④ 30000投資
倍率 = 増加ダイヤ数 ÷ 30000

総合倍率

4段階の投資額を合計すると、

30 + 300 + 3000 + 30000
= 33330

となります。

総合倍率は、

総合倍率
=（④の獲得後ダイヤ数 − ①の元ダイヤ数）÷ 33330

で計算します。

⸻

⚠️ 倍率上限

表示倍率には最大2.000倍の上限を設定しています。

例えば、

1.250倍 → 1.250倍
1.850倍 → 1.850倍
2.000倍 → 2.000倍
2.500倍 → 2.000倍
3.000倍 → 2.000倍

となります。

内部計算結果が2倍を超えた場合も、画面上では2.000倍として表示されます。

⸻

💾 自動保存

入力したダイヤ数はブラウザの localStorage に自動保存されます。

そのため、

* ページを閉じる
* ブラウザを終了する
* ホーム画面からアプリを終了する

といった操作を行っても、次回起動時に入力内容を復元できます。

保存される内容

* ①30投資の元ダイヤ数
* ①30投資の獲得後ダイヤ数
* ②300投資の元ダイヤ数
* ②300投資の獲得後ダイヤ数
* ③3000投資の元ダイヤ数
* ③3000投資の獲得後ダイヤ数
* ④30000投資の元ダイヤ数
* ④30000投資の獲得後ダイヤ数

⸻

🗑️ リセット

「リセット」ボタンを押すことで、

* すべての入力値
* 各増加ダイヤ数
* 各倍率
* 総合倍率
* localStorageに保存されたデータ

をまとめて消去できます。

誤操作防止のため、リセット前に確認ダイアログを表示します。

🚀 GitHub Pagesで公開する場合

index.html

manifest.json
service-worker.js

Service Workerを正常に動作させるには、HTTPS環境が必要です。

GitHub PagesはHTTPSに対応しているため、そのままPWAとして利用できます。

⸻

🔒 データについて

入力データはサーバーへ送信されません。

すべて利用している端末のブラウザ内に保存されます。

そのため、端末やブラウザのデータを削除した場合、保存されている入力内容も失われます。
